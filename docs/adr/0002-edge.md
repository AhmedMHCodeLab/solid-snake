# 0002 Front Door Premium with WAF and Private Link on the default endpoint; open access

**Context.** Owner decisions: private-first and highly secure; no custom domain; access fully open; up for about a day. Options compared in INFRA-PLAN.md: Container Apps ingress alone (no WAF, public origin), Front Door Standard (custom WAF rules only, public origin restricted by service tag), Front Door Premium (managed rules, bot rules, Private Link origin). The Front Door base fee is billed per hour used (learn.microsoft.com/azure/frontdoor/billing), so Premium costs about $11 per day.

**Decision.** Front Door Premium on its default `*.azurefd.net` endpoint with a managed certificate. WAF with the default and bot manager rule sets, a rate limit on `/api/`, Prevention outside dev. The Container Apps environment has public network access disabled and is reached only over Private Link.

**Consequences.** The origin cannot be reached around the WAF (R1). With open access, anyone holding the link can act as analyst or supervisor; the WAF rate limit and the share quota are the only abuse controls. This is the owner's call and is recorded here, not mitigated.

**Revisit when** a real client needs access control (add Container Apps built-in authentication with Entra ID) or a custom domain.
